# /record-response

Record a response already sent and close its request.

Read CLAUDE.md first. Run `npm run requests -- record-response --json` with the required flags shown by `npm run requests -- help`. Supported flags: --request, --outcome, --reason, --authority, --complaint-notice, --date, --evidence, --actor.

Read the request first. Use the operator-provided actor and evidence. Only record the change the operator has instructed. Never invent missing fields.



Only record a response already sent by the authorised officer. Ask for its evidence reference, actual date, outcome, legal basis and complaint-rights notice. The command does not send or release documents.

Present the result in plain words. List candidates when ambiguous and obtain the exact id. Keep generated material private. Drafts never send.
