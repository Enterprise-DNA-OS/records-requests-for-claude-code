# Work from the request, not a queue of screens

The information officer asks for the overdue desk, a department's unfinished searches or one request's evidence. The agent reads the database and runs the relevant command. Reports are branded read-only HTML. All operational changes use the same CLI.

A public portal gives requesters forms, uploads and delivery links. Mobile apps give field staff offline capture. Document tools give visual redaction. This base does not provide those screens, offline access, concurrent browser sessions or document editing. It stores metadata, review decisions and references. It does not inspect or release document binaries.
